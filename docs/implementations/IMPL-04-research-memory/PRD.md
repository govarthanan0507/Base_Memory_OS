# IMPL-04 PRD — Research Memory

**Version:** 0.1

## Product intent

Make external research traceable inside Personal Work Memory by turning sources into durable, deduplicated artifacts before adding deeper content understanding.

## First user experience

1. Provide a research URL.
2. Normalize it into a canonical form.
3. Identify a conservative source category.
4. Store the source as an artifact with provenance.
5. Re-registering the source returns the same artifact identity.

## Priorities

**P0:** canonical URL identity, artifact registration, provenance, deduplication.

**P1:** fetched source metadata, source-content snapshots, repository/video/document extraction and source relationships.

**P2:** semantic research summaries, citation graphs, idea/project linkage and cross-source synthesis.

## Constraints

Local-first, vendor-independent, source-preserving and evidence-oriented. URL registration itself does not imply that external content was fetched or verified.
