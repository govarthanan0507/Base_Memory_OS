# IMPL-06 — Continuity OS PRD v0.1

## Product surface

The continuity dashboard is the V0 home surface for project awareness.

It answers, at a glance:
- which projects are known;
- their recorded status;
- the latest linked conversation;
- how many unresolved candidate threads are recorded;
- how many artifacts are linked.

## UX constraints

- compact
- deterministic
- evidence-based
- no forced prioritization
- no destructive behavior

## V0 priority

Dashboard first; detailed project re-entry remains one command away through `reentry-project`.
