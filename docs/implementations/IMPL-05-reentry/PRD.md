# IMPL-05 — Re-entry PRD v0.1

## Product behavior

Re-entry is a compact project briefing, not a chat replay. The first screen/output should answer:

- What project is this?
- What was the last known conversation?
- What activity was recorded recently?
- What unresolved candidate threads remain?
- Which artifacts and durable memories are connected?

## UX principles

- evidence first
- concise sections
- explicit empty states
- no fabricated “next action”
- no destructive actions
- deterministic output for the same stored state

## V0 priority

The project re-entry brief is the primary V0 surface. Conversation re-entry remains supported as an existing lower-level continuity capability.
